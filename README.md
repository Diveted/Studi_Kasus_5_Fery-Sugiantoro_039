# Sistem Pemesanan Hotel

Program ini digunakan untuk menghitung biaya pemesanan kamar hotel berdasarkan jenis kamar dan lama menginap.

## Penjelasan Kode

- def hitung_biaya() digunakan untuk menghitung total biaya kamar.
- if dan elif digunakan untuk menentukan tarif kamar.
- input() digunakan untuk memasukkan data pemesanan.
- check_out - check_in digunakan untuk menghitung lama menginap.
- return digunakan untuk mengembalikan hasil perhitungan.
- print() digunakan untuk menampilkan hasil pemesanan.

## Tarif Kamar

- Standard = Rp200.000/malam
- Deluxe = Rp350.000/malam
